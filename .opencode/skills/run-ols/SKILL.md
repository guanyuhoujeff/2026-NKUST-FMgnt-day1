# 下模型、跑 OLS、檢查結果

## 做事的規則

1. **一次只做使用者指定的那一步**，做完就停，不要自己往下做。
2. **模型由使用者決定**：Y、X、控制變數、固定效果、常數項、標準誤都照使用者的描述，不可以自己增減變數、改定義或換估計方法。
3. 使用者說的變數在 `panel.csv` 找不到對應欄位時，**停下來說「找不到哪一個」**，不可以自己猜一個欄位代替。
4. 所有數字都從程式輸出來，不可以手寫或自己算。

## model.json 的格式

```json
{"y": "依變數欄名",
 "x": ["主要解釋變數和控制變數的欄名，主要解釋變數放第一個"],
 "fixed_effects": ["IND", "Year"],
 "ind_ref": "當對照組的產業虛擬變數欄名",
 "year_ref": "當對照組的年度虛擬變數欄名",
 "constant": true,
 "se": "nonrobust",
 "N": 筆數}
```

- `fixed_effects` 的 `IND` 代表 `panel.csv` 裡所有 `IND_` 開頭的欄位，`Year` 代表所有 `Year_` 開頭的欄位。
- `se` 只能是 `"nonrobust"`（一般 OLS 標準誤）、`"HC1"`（穩健標準誤）或 `"cluster"`（叢集標準誤），照使用者說的填。

## 寫 model.json 的步驟

1. **先讀 `panel.csv`**：列出它的欄位名稱，數它有幾筆（不含標題列）。
2. 使用者說的每一個變數，對到 `panel.csv` 裡**一模一樣的欄名**；對不到就停下來說「找不到哪一個」。
3. `ind_ref`、`year_ref` 各從 `panel.csv` 實際有的 `IND_`、`Year_` 欄位裡挑一欄（沒指定就挑排序第一個）。
4. `N` 填第 1 點數到的筆數，**不可以留空或寫 null**。
5. 寫完後讀回 `model.json`，用中文逐項複述：Y、X、控制變數、固定效果和各用哪一欄當對照組、有沒有常數項、標準誤、樣本幾筆。

## 跑 OLS 的規則

- **完全照 `model.json`**：`x` 裡的變數一個不多一個不少。
- 固定效果：放進 `IND_` 開頭的所有欄位但刪掉 `ind_ref` 那一欄；放進 `Year_` 開頭的所有欄位但刪掉 `year_ref` 那一欄。
- **常數項**：`constant` 是 `true` 就要放。產業和年度虛擬變數各刪一類當對照組，所以要有常數項；不可以說「截距被固定效果吸收所以不放常數」——那只在虛擬變數全部放、一類都不刪時才成立。
- 用 `statsmodels` 的 `OLS`；`se` 是 `"nonrobust"` 時用預設的標準誤。

## results.csv 的格式

- UTF-8 CSV，欄位是 `variable,coef,t`。
- 依序列出常數項（variable 寫 `const`）和 `model.json` 的每一個 x；虛擬變數的係數不用列。
- 最後兩列是 `N` 和 `adj_R2`，數字放在 `coef` 那一格，`t` 留空。
- 跑完另外印出放進迴歸的變數數目：常數項幾個、X 和控制變數幾個、產業虛擬變數幾個、年度虛擬變數幾個、合計幾個；再印出 results.csv 的內容。

## 檢查結果的原則

檢查要**用程式重新算一次再比對**，不可以直接寫「通過」。每一項都寫出「應該是多少、實際是多少」，由程式判斷是否通過。只要有一項沒通過，總結就不能寫「全部通過」。

檢查程式讀 `panel.csv`、`model.json`、`results.csv`，結果寫成 `check.md`：一張表，欄位是「檢查項目 | 應該是 | 實際是 | 通過？」，「通過？」填「是」或「否」；表的下面寫一句總結（全部通過，或列出沒通過的項目），再印出 check.md 的內容。

**至少檢查這 6 項：**

1. results.csv 的 `N` 等於 panel.csv 裡 y 和每一個 x 都有值的筆數。
2. results.csv 列出的變數（`const`、`N`、`adj_R2` 以外）跟 model.json 的 x 一模一樣。
3. 有 `const` 那一列。
4. 產業、年度虛擬變數各放進「全部欄數減 1」欄，刪掉的正好是 model.json 的 `ind_ref` 和 `year_ref`。
5. 放進迴歸的變數合計數目，等於 1 ＋ x 的個數 ＋ 放進去的產業欄數 ＋ 放進去的年度欄數。
6. 照 model.json 重跑一次 OLS，每一個係數和 t 值都跟 results.csv 一樣（差在 0.0001 以內）。
