# Day 1｜用 opencode 一步一步做出研究大表、跑 OLS

> 學生用。每一格「指令」整段複製貼到 opencode；它做完後，照「核對」那一行檢查，對了才貼下一步。
> 核對數字是老師 **2026-10-14** 從 TEJ 匯出的資料算的。
> **TEJ 會修正歷史資料**，你匯出的日期不同，第 5 步以後的數字可能差幾筆到幾十筆、係數差在小數第 3 位，這是正常的。差上百筆、或第 1–4 步就對不上，才是做錯了。
> 三個階段**各開一個新對話**（輸入 `/new`）；同一階段裡的步驟都在同一個對話裡做。

## 指令怎麼寫：白話講四件事

每一條指令都只講四件事：**① 用哪個檔、② 要做什麼（白話）、③ 存成什麼、④ 印什麼給我核對**。開頭指給它「照哪個 skill 的第幾步」，最後加「只做這一步」。

**看它有沒有真的載入 skill**：畫面上要出現 `Skill "tej-data"`（第 11–13 步是 `run-ols`）。沒出現就再說一次「先載入 tej-data skill」。老師測試時，沒真的載入的那幾輪都很早就做錯。

欄位叫什麼、怎麼篩、留哪些欄位這些細節，寫在 `tej-data`、`run-ols` 兩個 skill 裡（`.opencode/skills/` 底下，可以打開來看）。那些細節是老師測試時 agent 一次次做錯之後補進去的，例如：它把欄位名稱改成 0、1、2；拿「證期會代碼」當公司代碼；印出來的筆數是對的、存進檔的卻不是。

建議：每一步先照前面投影片「整理」那一頁的內容，自己用四格寫一句，再對照下面的指令。

## 開始之前：下載工具包（只做一次）

1. 開一個**新的、空的資料夾**當你的工作資料夾（放哪裡、叫什麼名字你自己決定）。
2. 在這個資料夾裡打開 opencode，貼這段：

```
請用 git 把 https://github.com/guanyuhoujeff/2026-NKUST-FMgnt-day1.git 下載到目前這個資料夾，檔案直接放在這一層，不要多一層子資料夾；資料夾裡原本的檔案不可以刪除或覆蓋。下載完列出這一層的檔案和 .opencode/skills 裡的資料夾。
```

3. **把 opencode 整個關掉再重開**（skill 只在 opencode 啟動時讀一次）。
4. 問它「你有哪些 skill？」，要看到 `tej-data` 和 `run-ols`。

**核對**：資料夾這一層有 `AGENTS.md`、`.opencode`、`data`、`教材`，沒有多一層 `2026-NKUST-FMgnt-day1` 資料夾。電腦沒有 git 的話：打開上面的網址，按綠色 **Code → Download ZIP**，解壓縮後整包放進你的資料夾（包括 `.opencode`）。

把 4 個 TEJ 檔放進 `data` 之後，再開始第 1 步。

## 階段一：做分析大表（第 1–10 步）

每做完一步，先核對再往下。數字不對就把「看到的症狀」告訴它，再叫它回 skill 對照那一步的做法，例如：

```
s1.csv 有 X 筆，應該是 Y 筆。請重新載入 tej-data skill，對照它寫的第 1 步做法，找出哪裡沒照做，修正 step1.py 後重跑。只修這一步。
```

### 第 1 步

**指令**

```
先載入 tej-data skill。第 1 步（照 tej-data skill 做法表的第 1 步）：借款明細只要每年 12 月那一期。程式存成 step1.py，結果存成 s1.csv，印出原本幾筆、留下幾筆、每一年各幾筆。只做這一步。
```

**核對**：筆數 **157,602**；年份 2008–2019 共 **12 年**；打開 `s1.csv` 看第一列，**原本 22 個欄位名稱都還在**（不能變成 0、1、2……）

### 第 2 步

**指令**

```
第 2 步（照 tej-data skill 做法表的第 2 步）：s1.csv 只留長期、固定利率的借款；同一筆借款會在好幾年重複出現，只算一次。程式存成 step2.py，結果存成 s2.csv，每做完一個動作就印出還剩幾筆。只做這一步。
```

**核對**：長期固定 **45,217**；刪掉空白後 **37,331**；去掉重複後 **32,245**

## 階段二：下研究模型（第 11 步）

**先開一個新對話**（在 opencode 輸入 `/new`），再貼這一階段的指令。前一階段的檔案都在資料夾裡，新對話會自己去讀；老師測試時每個階段都是新對話。

模型是**你決定的**：指令裡「Y 是…，X 是…，控制變數是…，有…固定效果」那一段，就是你的研究模型。AI 只負責把它寫成 `model.json`，再複述給你看。

### 第 11 步

**指令**

```
先載入 run-ols skill。第 11 步（照 run-ols skill 寫 model.json 的步驟）：我的研究模型是：Y 是 Rate，X 是 TCRI，控制變數是 Size、MB、ROA、Debt、LLoan、LMaturity、CollateralD，有產業和年度固定效果，有常數項，標準誤用一般 OLS。資料是 panel.csv。把模型寫成 model.json，再用中文複述一次給我看。不要跑迴歸。只做這一步。
```

**核對**：它複述的模型跟你寫的一樣：Y 是 `Rate`；X 是 `TCRI`；7 個控制變數一個不少；產業和年度固定效果都有，各刪一欄當對照組；**有常數項**；標準誤是一般 OLS；樣本 **19,344** 筆。再打開 `model.json` 看一次：`constant` 是 `true`、`se` 是 `"nonrobust"`

## 階段三：跑 OLS 並檢查（第 12–13 步）

**先開一個新對話**（在 opencode 輸入 `/new`），再貼這一階段的第一個指令。前一階段的檔案都在資料夾裡，新對話會自己去讀；老師測試時每個階段都是新對話。

### 第 12 步

**指令**

```
先載入 run-ols skill。第 12 步（照 run-ols skill）：照 model.json 跑 OLS。程式存成 step12.py，結果存成 results.csv，印出結果和放進迴歸的變數數目。只做這一步。
```

**核對**：變數數目：常數 1 ＋ X 和控制變數 8 ＋ 產業 **32** ＋ 年度 11 ＝ **52**；有 `const` 那一列；N＝19,344；adj R² ≈ **0.32**（若接近 0.9，多半是常數項被拿掉）；係數對照下方「參考答案」

### 第 13 步

**指令**

```
第 13 步（照 run-ols skill 的檢查清單）：寫一支程式檢查這次迴歸有沒有照 model.json 跑對，每一項都要寫出應該是多少、實際是多少、有沒有通過。程式存成 step13.py，結果存成 check.md，印出 check.md。只做這一步。
```

**核對**：`check.md` 有 6 列以上，每一列都寫出「應該是」和「實際是」，「通過？」全部是「是」；總結寫「全部通過」。再抽一列自己對：例如 N 那一列，「應該是」跟你第 9 步的筆數一樣嗎？

## 發現錯誤時怎麼下修正指令

同一個 opencode 對話裡再打一句，寫清楚四件事：**錯在哪、應該是什麼（附理由）、要改哪幾個檔、改完印出來給我看**。例如：

```
我說要有常數項：產業和年度虛擬變數各刪一類當對照組，所以要放常數項。請把 model.json 改成有常數項，改完把 model.json 印出來給我看。
```

只說「不對」或只講症狀，它常常只改其中一個檔。
